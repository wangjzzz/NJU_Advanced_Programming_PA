# Synera: Synergy Auto-Arena

基于 Qt6 + C++17 的单机自走棋游戏（PVE），高级程序设计课程 PA 项目。

## 快速运行

```powershell
cmake -S . -B build
cmake --build build --config Release
.\build\Synera_Starter.exe
```

## 玩法

- **准备阶段**：商店买英雄 → 拖拽布阵到棋盘下半区 → 装备穿戴 → 【开始战斗】
- **战斗阶段**：自动索敌、普攻回蓝、满蓝放技能，直到一方全灭
- **结算阶段**：胜利得金币 + 概率掉装备，失败扣血；通关 10 轮胜利
- 右键出售棋子，或拖到备战区右侧红色出售区出售
- 每 10 金 +1 利息（封顶 5），连胜/连败额外奖励

## 架构

三层分离：**entity**（数据/多态）→ **core**（逻辑/规则）→ **gui**（渲染/输入）。

- UnitItem 只负责画图 + 发射鼠标信号，不碰游戏逻辑
- DragDropHandler 独立处理拖拽校验与执行
- BoardGeometry 独立处理所有坐标变换
- Game 作为协调者串联各模块

## 第四阶段扩展实现

### 1. 金币利息与连胜/连败奖励

**利息**：每轮准备阶段开始时，每持有 10 金币额外 +1 金，封顶 +5 金。

**连胜/连败**：连赢或连输触发额外金币奖励：

| 连胜 | 额外金币 | 连败 | 额外金币 |
|------|----------|------|----------|
| 2 场 | +1     | 2 场 | +1 |
| 4 场 | +2     | 4 场 | +2 |
| 6 场 | +3     | | |

界面金币标签旁实时显示 `[连胜3]` 或 `[连败2]` 和 `(利息+3)`。

实现文件：`core/player.h/cpp`（字段与计算）、`core/game.cpp`（阶段流转时发放）、`gui/gamewindow.cpp`（界面显示）。

### 2. 攻击连线可视化

战斗时每次普攻从攻击方到目标画一条半透明连线，受击瞬间单位闪白。

| 类型 | 颜色 | 效果 |
|------|------|------|
| 伤害攻击 | 🟠 橙黄 | 从攻击方边缘 → 目标边缘 |
| 治疗（牧师） | 🟢 绿色 | 从牧师 → 受伤友军 |

连线每帧重新生成（持续 ~16ms），战斗结束自动清除。

实现文件：`core/combat_system.h/cpp`（`AttackLineRecord` + `isHeal` 标记）、`core/game.cpp`（`drawAttackLines`）、`entity/unit.h/cpp`（`m_hitFlashTimer`）、`gui/unititem.cpp`（受击闪白绘制）。

### 3. 一些视觉增强

- 技能释放时头顶弹出 "SKILL!" 金字（50帧渐隐）
- 羁绊激活时场上单位底部显示彩色空心光环（橙/紫/蓝/绿/金）
- 战胜掉落装备时装备栏旁显示 "掉落装备!" 提示
- 战斗结束浮层（无 Windows 提示音）
